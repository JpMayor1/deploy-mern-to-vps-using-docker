# Prerequisites

Before starting, make sure you have the following:

## Accounts

- GitHub
- Docker Hub
- Cloudflare
- MongoDB Atlas

## Tools

- Docker Desktop (local)
- Git
- Terminal

## Server

- Ubuntu VPS (20.04 or 22.04)
- SSH root access

## Project

- `/frontend` (React + Vite)
- `/backend` (Node + Express)
- `.env.production` files inside frontend & backend
